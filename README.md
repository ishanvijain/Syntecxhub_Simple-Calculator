# Simple Calculator

A command-line based simple calculator built using Python.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Clear screen option
- Exit option
- Divide-by-zero handling
- Invalid input handling

## Technologies Used
- Python
- OS Module

## Project Structure

simple-calculator/
│
├── calculator.py
├── README.md
└── requirements.txt

## How to Run

1. Clone the repository

git clone <repository-link>

2. Open project folder

cd simple-calculator

3. Run the program

python calculator.py
